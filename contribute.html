Access BC: add to the map

For Access BC's volunteers: add accessible entrances, paths, and notes about buildings where the map is missing them. What you add appears in Access BC straight away, marked not verified yet, until the Access BC team checks it. See the mapping guide for what to look for. Checking existing data is on another page.

Contributions aren't set up yet on this copy of Access BC (see docs/data-collection/contributions-setup.md).
